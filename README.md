# GOLD INTELLIGENCE V1.4

国际黄金、国内金价与渠道比价仪表盘，支持 Streamlit Community Cloud 和 Mac 本地运行。入口为仓库根目录 `app.py`。

## 预测、醒目因子提醒与免费对话（V1.4）

首页“预测中心”直接显示1、3、7、30、90个交易日（1个交易日不等于自然24小时）的期货情景预测，包含中心情景、理论80%/95%区间及分布假设下的上涨/震荡/下跌概率。标明实际生成时间、价格基准日、因子日期和下次数据检查计划；数据不足、过旧或来源失败时明确说明。检查计划不代表来源一定发布新数据，交易日日期仅排除周末。

优先突出10年实际收益率与美元指数，展示当前观测、变化方向和核验状态；风险情绪与油价保留条件性说明。这里的优先级是阅读顺序，不是固定模型权重或因果效应。提醒阈值在页面公开，缺失或过期数据不冒充中性信号。

预测及美元/VIX/原油提醒统一使用纽约17:00完成筛选后的日线；在此之前剔除当日价格，避免把盘中未完成日线用于模型。该筛选不是官方结算确认，也不是完整的交易所假日表。预测统一使用最近最多5年有效期货历史；侧栏日线范围只影响走势图，不改变模型训练范围。模型同时报告时间顺序留出集的方向准确率、训练集多数方向在同一留出集的简单基准，以及实际入模的因子。当前单次留出检验不证明长期预测能力，理论区间也尚未完成各周期覆盖率校准。实际利率等历史不足时不宣称已进入模型。

“对话助手”是免费规则问答，回答站内报价、预测、因子、更新计划、准确率、国内比价和默认斐波那契；不调用外部AI。每条回答有时间，旧回答不会随数据变化被静默改写。当前支持限定的预测周期，不把不支持的周期偷偷换成7天，也不能确定某天必涨或具体买入时机。聊天内容由本网站服务器处理，不能当作完全离线或端到端加密对话。

新图标通过内置图像生成工具制作，原始PNG与设计提示词存于 `assets/`；网页favicon、首页和Mac应用使用同一标识。Mac离线资料仍为历史快照；预测与问答使用联网的现有Streamlit服务。原生应用版本1.4.0，临时签名，无Apple公证。

## 黄金逻辑与历史复盘（V1.3）

新增首页“黄金逻辑与历史”，按黄金货币史、定价驱动、长期走势、关键事件、技术位置的顺序阅读。

- 1971年1月起的黄金月均价，名义美元/金衡盎司；月度资料与近期现货、期货日线独立显示。
- 默认随包快照截至2026年10月，共670个月；后台每天检查公开镜像，不阻塞首次显示。原始来源为世界银行 Pink Sheet，下载连接来自 datasets/gold-prices 第三方公开镜像，并明确标注。最近三个月抽样核对官方月报一致，不宣称逐月独立复核。
- 对数/普通价格轴、年度变化、20%/30%月度反转阶段复盘。年度变化为最近月均价对上年12月均价；拐点由后续价格事后确认，最后一段明确为未确认。
- 12个精选节点，每条含原始资料链接、事实、传导假设、相反力量与验证条件。事件窗口为前一个月到事件月之后第3个月的月均价变化，不代表因果效应；最新动态见国际新闻。
- 斐波那契可选择 COMEX GC=F 期货日线或长期月均价，自动区间高低点或手动选日期。显示23.6%、38.2%、50%、61.8%、78.6%回撤和127.2%、161.8%两点延伸，含公式、锚点、最近上下方观察位和CSV导出。
- 技术位置用价格、短期均价、长期均价的排列描述偏强/偏弱/震荡，不等于未来方向概率，更不等于黄金内在价值。
- 长期范围控制图表、年度变化、事件和月均价CSV；图表下方的缩放条仅缩放图表。斐波那契有单独的数据口径与范围。

## 下载 Mac 桌面应用

在页面底部点击“下载 Mac 应用 ZIP”，或下载仓库 `downloads/GOLD_INTELLIGENCE_Mac.zip`，解压后打开“黄金智能分析中心.app”。支持macOS 12及以上，Apple芯片和Intel通用，无需安装Python。

桌面版是现有 Streamlit 分析中心的原生窗口，在线行情和交互分析依赖联网及云端网站服务。顶部“离线历史资料”可打开随包历史快照，不会自动更新；离线模式不提供最新行情。外部来源链接使用默认浏览器打开。

本应用使用本地临时签名，未进行 Apple Developer ID 签名或公证。首次打开若被macOS拦截，可按照系统提示在隐私与安全性中确认允许，或继续使用下方网页版；不需要关闭系统安全防护。

网页版：https://gold-intelligence-lzm.streamlit.app/

应用原生代码在 `mac_app/GoldIntelligence.swift`，可审查和自行编译。开发者在Mac安装Xcode命令行工具后，可运行 `python mac_app/build_mac.py --output /tmp/gold-mac-build` 构建通用应用。

## 收益率最新数据与延迟核验（V1.2.2）

新增美国财政部当月XML直连，分别读取实际10年TC_10YEAR与名义2年BC_2YEAR、名义10年BC_10YEAR。财政部、H.15、FRED按观测日期选最新，同日财政部优先；旧来源新抓取成功不能让较新的观测日期倒退。短月初可补充上个月数据，当月网络故障不冒充上月数据已是最新。

关键收益率每15分钟检查。卡片和明细分别显示观测日、当前观测抓取时间、最近完成检查时间、来源标注更新时间或发布日期。XML updated按来源元数据标注，不冒充精确首次发布时间；未提供的发布时间明确标为未提供。

延迟状态区分已核验日度、可能延迟、检查失败使用缓存、核验已过期和来源返回旧数据。参考纽约时间17:00、美国联邦假日/周末及Good Friday估计应有的观测日，临时休市或发布延误以官方说明为准；该基准不是逐笔实时行情承诺。

[财政部XML官方说明](https://home.treasury.gov/treasury-daily-interest-rate-xml-feed)

## 收益率修复（V1.2.1）

首页显示10年期实际收益率（TIPS）和2年期名义收益率，标注相对上一有效观测日的上升、下降或持平，以及变化基点与观测日期。宏观指标页新增三条美债收益率的曲线和明细，包括10年期名义收益率。

关键收益率不再等待FRED宏观批量下载：独立获取DFII10、DGS2单项CSV，并通过美联储H.15官方日度发布补充。H.15中的名义与通胀保值国债（TIPS）行分开解析，绝不用名义值填补实际收益率。合并同口径观测时保留来源，较新采集值修订重叠日期。

收益率每天按官方发布频率更新，网站每15分钟检查；不是盘中实时报价。变化按相邻有效观测值计算，1基点=0.01个百分点，未发布日和缺值不补0。备用源只有数日时会注明样本不足，不伪造长历史。

数据定义：[FRED DFII10](https://fred.stlouisfed.org/series/DFII10)、[FRED DGS2](https://fred.stlouisfed.org/series/DGS2)、[美联储H.15官方发布及口径](https://www.federalreserve.gov/releases/h15/)。

## 功能

- 国际黄金：Gold API 现货参考报价；COMEX `GC=F` 期货日线、技术指标与统计预测分开标注。Yahoo公共请求失败时尝试一次yfinance备用抓取，仍失败则退避。
- 国内走势：上海黄金交易所 Au99.99 最近30个自然日内已公布的人民币元/克日收盘价。
- 国内渠道：SMM 品牌黄金、金条、回收与换购公开挂牌价，按类别、成色、日期和客户交易方向分别比较。
- 彩色比价：鲜绿为组内最低价，亮红为最高价，金黄为中间价或同价；并列价格同时标注，旧日期不混入当前排名。支持CSV导出。
- 银行积存金：支持手动录入建行、工行、农行、中行、招行、交行及其他渠道的报价；明确标注未核验，与公开挂牌分开比较。银行自动报价尚未接入。
- 宏观与新闻：FRED九项指标，GDELT、BBC World、美联储和BLS官方RSS独立更新。
- 后台采集：并行请求、成功数据缓存、失败退避、观测时间与采集时间分开显示。单个来源故障不会阻止其他模块展示。

## 云端部署

Streamlit 应用指向本仓库 `main` 分支，入口 `app.py`。需要同时保留 `gold_intelligence/`、`requirements.txt` 和 `.streamlit/config.toml`，不要只复制入口文件。

依赖自动根据 requirements.txt 安装；无需付费AI密钥。云端配置使用平台默认监听地址。

云端本地缓存保存在实例的 `data/cache/`，休眠、重建或替换实例后可能丢失。报价源在不同网络环境可能超时，查看“数据诊断”了解具体连接状态。

## 本地运行

建议Python 3.11或更新版本。Mac可双击 `启动.command`，也可执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address=127.0.0.1
```

测试及取数诊断：

```bash
python -m unittest discover -s tests -v
python 诊断数据源.py
```

完整缓存页面测试需要先运行取数诊断，没有缓存时会跳过；其他回归测试可离线运行。

## 报价与模型口径

挂牌价可能不含工费、手续费、地区优惠，不能视作最终到手价。高低标记仅表示所选可比组内的数值大小。银行手动报价按同日、同方向、同成色、距组内最新报价15分钟内比较；记录保存在当前浏览器会话，可导出JSON。

上金所走势图不是国际金价换算。品牌挂牌源为第三方SMM汇总，不是品牌官方报价接口。现货与期货不会混成同一价格序列。

预测沿用V1的Ridge日线统计模型，周期按交易日标注，尚未完成各周期区间覆盖率或事件幅度回测。宏观历史值可能修订，标题规则仅表示传导假设。
